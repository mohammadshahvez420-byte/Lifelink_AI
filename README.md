## Project Architecture

LifeLink AI follows a layered architecture:

- Frontend (React)
- Backend (FastAPI)
- Database (PostgreSQL)
- AI Module (Scikit-learn)

The frontend communicates with the backend using APIs.
The backend handles business logic, database operations, and AI integration.




# 🩸 LifeLink AI

## Smart Blood Donor Recommendation & Emergency Response System

### 📌 Project Overview

LifeLink AI is an AI-powered blood donor management platform designed to connect blood donors, patients, hospitals, and blood banks efficiently.

The system helps users search for suitable blood donors, create emergency blood requests, and receive intelligent donor recommendations using Artificial Intelligence.

---

## 🎯 Objectives

- Register blood donors
- Search donors by blood group
- Create emergency blood requests
- Manage donor availability
- Recommend the best donor using AI
- Maintain donation history

---

## 🛠️ Technology Stack

- Frontend: React
- Backend: FastAPI
- Database: PostgreSQL
- Machine Learning: Scikit-learn
- Version Control: Git & GitHub
